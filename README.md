# The Playbook - Portfolio

A football strategy-themed portfolio showcasing my work in sports analytics and human-centered design.

## 🎯 Overview

This portfolio is styled like a personal football strategy book, merging product, design, and analytics through clean case studies, chalk-style visuals, and tactical sectioning.

## 🎨 Design Features

- **Theme**: Football playbook-inspired design with chalkboard aesthetics
- **Colors**: Dark green background (#2E3C2F) with bright red accents (#ff3b30)
- **Typography**: Space Grotesk for headings, Inter for body text
- **Animations**: Smooth transitions, scroll reveals, and stat counters
- **Textures**: Chalk-style overlays and football route patterns

## 🧱 Structure

- **Header**: Fixed navigation with smooth scrolling
- **Hero**: Bold headline with animated underline
- **Featured**: Main project showcase with flip card animation
- **Projects**: Grid layout with hover interactions
- **Stats**: Animated counters and metrics

## 🛠 Technical Details

- Built with vanilla HTML, CSS, and JavaScript
- Responsive design with CSS Grid and Flexbox
- Intersection Observer for scroll animations
- Custom SVG patterns and overlays
- Performance optimized assets

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required!
