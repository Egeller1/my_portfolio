Overview

TextSwap is a fully functional student marketplace for buying and selling textbooks, designed and built entirely from scratch. I led product management, design, and development to launch a live, server-backed platform using Java, TypeScript, and CSS.

Product Story

I identified the need for an easier way for students to exchange textbooks on campus, where existing options were fragmented or inconvenient. TextSwap lets students search available textbooks, post new offers, and manage incoming buying and selling offers, all through a clean and responsive interface. I built and led the entire project from planning through deployment.

Key Contributions

  • Built the entire front-end interface with CSS and TypeScript
  • Developed key marketplace features: search, post offers, manage offers
  • Designed UI/UX for fast, simple navigation
  • Connected front-end with Java server backend to create a fully operational service
  • Led product design and iteration based on testing and feedback

Closing Thoughts

TextSwap was my first experience independently managing a product from idea to launch, combining technical development with product leadership. The project sharpened my ability to design user-centered experiences and deliver working software within a tight timeline.
