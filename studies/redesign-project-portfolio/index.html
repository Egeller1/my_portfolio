🎯 Introduction & Project Goals

As one of the few kosher restaurants in my hometown of Riverdale, New York, Kai Fan has long been a go-to option for delivery. I chose to redesign Kai Fan's website to address its outdated design, confusing navigation, and poor visual hierarchy, all of which created significant barriers to an enjoyable user experience.

My overarching goal was to build a modern, responsive, and visually appealing interface that prioritizes user needs. By streamlining navigation and ensuring clarity in design, I aimed to help customers seamlessly find essential info—like hours, location, and menu options—while reflecting Kai Fan's brand identity.

Key Focus: We'll walk through the usability analysis, redesign process, and final implementation that transformed Kai Fan's online presence into a user-friendly experience.

🔍 Usability Analysis

Using five core criteria—Efficiency, Memorability, Learnability, Conceptual Model, and Accessibility—I analyzed how the original Kai Fan website impacts user interactions and where it falls short.

Efficiency: Minimizing Wasted Steps & Friction

  • The "A Destination" section tons of space with only two lines of text, wasting valuable screen real estate while also looking visually unnapealing
  • Multiple "Order Online" buttons create confusion about which one to use.
  • The site lacks a built-in menu page—users must click "Order Online," leading to an external site and adding friction for simple menu browsing.
  • Key info like business hours and location is buried at the bottom, forcing users to scroll and search for basic details.
  • On mobile, unoptimized images slow loading times, further reducing efficiency.
  • Repetitive promotional text ("All you can eat sushi is back…") clutters the homepage, making it harder to find important information.

Memorability: Helping Returning Users Recall the Site

  • Text-heavy promotions precede essential details (like hours, location, and food options), making users repeatedly hunt for key info.
  • Large image captions ("FRESH INGREDIENTS," "MASTER CHEF") appear interactive but aren't clickable, creating confusion on subsequent visits.
  • A lack of a distinctive color scheme or typography makes it difficult for returning users to recognize Kai Fan's site from others.

Learnability: Quick Onboarding for New Visitors

  • The "Order Online" button is not very noticeable, it blends into the background due to a thin white outline that contrasts poorly.
  • No hover effects or animations guide a first-time user's attention.
  • The prominent "All you can eat sushi" banner competes visually with key navigation elements.
  • Outdated visual hierarchy leads to multiple large text elements vying for attention.

Conceptual Model & Accessibility

  • The site funnels menu browsing into an external ordering system, breaking users' expectations.
  • Contrast issues: White or light-colored text over background images fails WCAG guidelines.
  • Redundant links and missing alternative text on images impair screen reader navigation.

🎨 Redesign Process

I structured my redesign around four key stages: establishing a style guide, creating wireframes, developing high-fidelity mockups, and implementing the final design.

Initial Analysis

The original website had several usability issues that needed to be addressed. This iterative approach helped ensure that each design decision was validated through user feedback and testing. By the end, I had a cohesive redesign that addressed the major pain points identified during the initial analysis.

🎨 Style Guide

A cohesive visual language was essential for transforming Kai Fan's digital presence. The style guide below establishes the foundation for a consistent, accessible, and engaging user experience.

Design System Highlights

  • Typography: A harmonious trio of Roboto (headlines), Open Sans and Raleway (body) creates clear visual hierarchy while maintaining readability across devices
  • Color Palette: Teal primary color conveys professionalism and trust, balanced with dark grey and white for optimal contrast and WCAG compliance
  • Components: Consistent button styles, hover states, and interactive elements ensure users always know what's clickable
  • Brand Elements: Modernized logo and iconography maintain brand recognition while elevating the visual experience

📱 Mockups

I produced high-fidelity mockups for mobile, tablet, and desktop views, ensuring a seamless experience across all devices. Each design variation maintains consistent elements while optimizing layouts for different screen sizes.

Key Design Decisions

  • Visual Hierarchy: Clear content structure with prominent call-to-action buttons
  • Navigation: Intuitive menu system with consistent placement across breakpoints
  • Content Flow: Logical progression from hero section to menu items
  • Responsive Elements: Flexible components that adapt to various screen sizes

Key Improvements

  • Enhanced Navigation: Intuitive menu structure with clear pathways to key information
  • Responsive Design: Seamless experience across all devices and screen sizes
  • Accessibility: WCAG-compliant color contrast, keyboard navigation, and screen reader support
  • Performance: Optimized images and assets for fast loading times
  • User Experience: Streamlined ordering process and clear calls-to-action
  • Visual Appeal: Modern aesthetic that maintains brand recognition

🎯 How Problems Were Solved

I implemented improvements to address the key issues identified in our analysis:

  • Efficiency: Redundant elements were eliminated and the navigation streamlined so that essential details like operating hours and location are immediately visible. Unnecessary content was removed to reduce friction.
  • Learnability: Micro-interactions, hover effects, and clear visual cues were introduced. Updated labels and guidance help new users quickly understand how to interact with the site.
  • Memorability: A distinctive color palette and updated typography were adopted. A persistent, intuitive navigation bar ensures returning visitors can easily recognize and recall the brand.
  • Conceptual Model: Content was reorganized to match user expectations. Misleading or static elements were removed to create a logical, intuitive flow throughout the site.
  • Accessibility: Color contrast was improved, descriptive alt text was added, and interactive elements were optimized to meet WCAG guidelines, making the site more inclusive for users with disabilities.

These enhancements transformed the site into a user-friendly and effective digital experience.

💭 Reflections

This project was a fun exercise that taught me several critical lessons:

  • Attention to Detail: Subtle choices like precise color contrasts and micro-interactions can make a huge difference.
  • User Focused Design: Aligning design decisions with real user needs and mental models is very important.
  • Balance of Aesthetics and Functionality: The project highlighted the necessity of creating a visually appealing interface without sacrificing usability or accessibility.

This was my first site redesign and I enjoyed looking at a site, assessing its strengths and weaknesses, and then fixing it myself!
